# Rhodium Germany

**Technologie für prüfbare Datenprozesse.**

Die zentrale öffentliche Präsentation und die Anfrage für einen individuell vereinbarten Pilot finden Sie unter [rhodium-germany.de](https://rhodium-germany.de/).

Dieses Repository dient ausschließlich der technischen Dokumentation historischer Prüfungen. Es ist kein Shop, kein Buchungsportal und kein öffentlicher Systemzugang. Frühere Preis-, Lizenzpartner- und Direktzahlungsangebote werden hier nicht mehr angeboten.

Die aktuelle Leistungsübersicht, Kontaktinformationen, das Impressum und die Datenschutzerklärung stehen auf der zentralen Website. Ein persönlicher Pilotzugang wird erst nach Vereinbarung und technischer Freigabe bereitgestellt.
